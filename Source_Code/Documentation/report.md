# Digital Logic Circuit Simulator using C++

## 1. Introduction

The Digital Logic Circuit Simulator is a C++-based project that simulates basic digital logic gates. It accepts binary inputs (0 and 1) and displays the output according to the selected logic gate.

## 2. Problem Statement

To develop a C++ program that simulates basic digital logic gates and produces the correct output for given binary inputs.

## 3. Objectives

* To understand the working of digital logic gates.
* To simulate logic gates using C++.
* To perform logical operations on binary inputs.
* To display the output of the selected gate.

## 4. Logic Gates Implemented

1. AND Gate
2. OR Gate
3. NOT Gate
4. NAND Gate
5. NOR Gate
6. XOR Gate
7. XNOR Gate

## 5. Working

1. Display the list of available logic gates.
2. Ask the user to select a logic gate.
3. Accept binary inputs (0 or 1).
4. Perform the selected logical operation.
5. Display the result.

## 6. Algorithm

1. Start the program.
2. Display the list of seven logic gates.
3. Ask the user to select a logic gate.
4. Accept the user's choice.
5. If the NOT gate is selected, accept one binary input (A).
6. Otherwise, accept two binary inputs (A and B).
7. Validate that the inputs are either 0 or 1.
8. Perform the selected logical operation using a switch statement.
9. Display the output.
10. Stop the program.

## 7. Sample Output

```text
=== DIGITAL LOGIC CIRCUIT SIMULATOR ===
1. AND Gate
2. OR Gate
3. NOT Gate
4. NAND Gate
5. NOR Gate
6. XOR Gate
7. XNOR Gate

Enter your choice: 1
Enter input A (0 or 1): 1
Enter input B (0 or 1): 1
Output = 1
```
